# 考研英语学习平台（v3.3.0）

  基于 Django 的考研英语一体化学习应用，现已打包为 **Windows 单文件桌面客户端**，覆盖 **词汇背诵 · 复习巩固 · 写作工坊 · 真题模拟 · 音乐与资料库**，开箱即用。

> **一句话**：市面上背单词 App 的大多数功能它都有；背过的词还会喂给写作工坊，AI 范文与模板严格贴合你的词汇水平——背得越多，写得越贴身。

## 功能与技术亮点

**市面上背单词 App 的大多数功能，这个 exe 都有**：全库配中英双语例句；顺序 / 乱序背诵、按批推进、每日任务按「目标 − 已学」自动补量；「昨日背错 → 昨日新学 → 今日到期」自动复习调度；打卡、统计、错词本、收藏、模拟考试、学习报告一应俱全。

在此之上还有市面少见的**写作工坊**：

- **词汇画像驱动代写**：读取你已掌握的词汇，生成严格贴合当前水平的范文（基础 / 标准 / 拔高三档），不堆超纲词
- **五维批改**：词汇 / 语法 / 连贯 / 切题 / 丰富度评分 + 逐句改错 + 高级表达推荐
- **真题全覆盖**：英语一 / 英语二 2006–2026 小作文、大作文、翻译 + 六级翻译，附长难句拆解、译文批改与命题规律分析
- **专属模板沉淀**：练习历史自动沉淀属于你的高分句型、易错点与词汇升级卡

**工程亮点**：

- **单文件桌面化**：程序与数据分离，升级只替换 exe、旧数据不受影响；首启自动建库并导入词库与真题；
- **混合判题引擎**：释义默写按「本地算法先筛 → LLM 精判 → 本地从严兜底」三级判定，明显一致的零 AI 调用，交卷按 10 题一组合并判定统一标准；作文与翻译批改由 LLM 按五维维度评分并沉淀错点
- **纯前端离线**：图表与图标全部本地打包，零构建依赖

## 技术栈

- **后端**：Python 3.13 + Django 4.2，SQLite 单文件数据库
- **桌面端**：pywebview（系统自带 WebView2 内核），PyInstaller 打包为单 exe
- **前端**：原生 HTML / CSS / JS，无构建工具；ECharts 本地打包离线可用、Phosphor Icons
- **PDF 导出**：reportlab（学习报告 / 真题资料导出）

## 快速开始

### 桌面客户端（推荐）

在product目录中dist下载 `word.exe` 后双击，弹出原生桌面窗口即可使用；首次启动约 1 分钟自动建库并导入词库与真题。

学习数据保存在 `word.exe` 同目录的 `data/` 文件夹中，更换电脑或重装前请先在设置页备份；启动异常可查看 `data/launch.log`。

### 开发模式

```
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
浏览器打开 http://127.0.0.1:8000/

## AI 模型配置

在 `/settings/` 页面添加模型并填写接口信息即可使用写作工坊、默写判定等智能能力；可为不同用途分别指定模型，未指定时自动使用第一个启用的模型，并提供一键连通性检测。
