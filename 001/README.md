# 考研英语学习平台

基于 Django 的考研英语一体化学习软件：词汇背诵（1866 词完整红宝书词库，中英例句）、间隔复习、拼写与释义默写（AI 判定）、模拟考试、写作工坊（历年真题 AI 代写/批改）、学习统计与计划，开箱即用。

## 使用

1. 双击 下载dist文件夹压缩包解压后打开dist文件夹下的`word.exe`，首次启动约 10–20 秒（自动建库并导入词库与真题）
2. 浏览器自动打开 `http://127.0.0.1:8000/`，未自动打开则手动访问
3. AI 功能需先在「设置」页配置模型 API key；关闭窗口或 `Ctrl+C` 退出
