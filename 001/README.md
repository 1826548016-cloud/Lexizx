# 考研英语学习平台

基于 Django 的考研英语一体化学习软件：词汇背诵（1866 词完整红宝书词库，中英例句）、间隔复习、拼写与释义默写（AI 判定）、模拟考试、写作工坊（历年真题 AI 代写/批改）、学习统计与计划，开箱即用。

## 使用

1. 下载 `dist.zip` 解压，双击 `word.exe`——弹出**原生桌面窗口**（无黑框、无需浏览器），首次启动约 1–2 分钟自动建库并导入词库与真题
2. AI 功能需先在「设置」页配置模型 API key
3. **关闭窗口即退出程序**

## 最后更新于2026年10月2日

学习数据保存在 `word.exe` 同目录的 `data` 文件夹中，删除软件前请先备份。启动异常可查看 `data/launch.log`。
