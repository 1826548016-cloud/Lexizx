# Lexizx 使用说明

本文面向 Windows 桌面版用户。软件无需注册账号，学习数据保存在本机。

## 首次启动

1. 从项目官方 GitHub Releases 下载最新版 `word.exe`，双击启动。首次启动会初始化本地数据库并导入词库、真题，可能需要等待一会儿。
2. 按页面提示阅读并确认软件内的用户许可与隐私说明。
3. 进入“设置”调整字体、主题、每日学习目标和发音偏好；不配置 AI 也可以使用词汇学习、复习和本地统计等功能。

如果 Windows 显示安全提示，请先核对文件是否来自项目官方 Releases；不要运行来源不明的同名文件。启动异常时可查看 `word.exe` 同目录下 `data/launch.log`。

## 配置 AI

1. 打开“设置 → AI 模型”，添加服务商、模型 ID、接口地址（服务商有要求时）和 API 密钥。
2. 点击模型连接测试，确认配置可用；再按需要为写作工坊、六级翻译、释义默写、导入识别等功能指定模型。未单独指定时会按页面说明使用默认模型。
3. 请妥善保管 API 密钥；密钥仅保存在本机数据库，不会上传服务器。

AI 请求需要网络，并可能产生第三方服务费用或消耗额度，费用规则以你所使用的服务商为准。服务商不可用、网络中断、密钥无效或额度不足时，AI 生成、批改和组卷可能失败；可先测试模型连接并检查服务商账户。

## 备份与恢复

### 备份

打开“设置 → 数据备份与恢复”，点击“下载备份”，在系统保存对话框中选择一个不随软件目录一起删除的位置。桌面版还会在本机 `data/backups/` 留存近期副本；本机副本不能代替放在其他磁盘或安全位置的备份。

备份文件是 JSON，可能包含学习记录、设置、对话和模型配置，其中可能包含明文 API 密钥；请像保管密码一样保管文件，不要上传到公开网盘或发送给他人。

### 恢复

1. 恢复前，先把当前数据也备份一份，以便需要时退回。
2. 在“设置 → 数据备份与恢复”选择此前生成的 `.json` 备份文件，等待页面提示成功后重新载入。
3. 恢复会按备份中包含的数据类别替换相应记录，并补齐目标库中缺少的词条；它不是简单的“只追加”，所以不要用旧备份覆盖你想保留的最新记录。

## 常见问题

- **AI 功能不可用**：检查网络、模型服务地址、模型 ID、API 密钥、账户额度。
- **翻译批改失败**：练习记录可能仍会保存，但 AI 评分/参考内容不一定可用；根据页面提示重试，并对照可靠资料自行核验。
- **更换电脑或重装**：先导出备份，再把备份复制到新设备的安全位置，然后在新安装的软件中恢复。
- **启动失败**：查看 `data/launch.log`，并确认程序目录及 `data/` 有读写权限。
- **重置学习进度**：此操作会清空学习进度、打卡和会话数据，且不可从本机自动撤销；确认前先备份。

## 功能边界与数据说明

- 这是本地单机学习工具，没有账号体系，也不提供多设备云同步；数据和自动备份副本保存在本机。
- 词汇学习、复习和本地数据查看不依赖 AI 服务；AI 生成、AI 批改、AI 组卷、智能导入等功能需要网络及用户自行配置的第三方模型。
- 用户主动使用 AI 时，相关输入内容会发送到用户配置的第三方服务。软件不会因此把完整学习数据库或 API 密钥发送给开发者自有服务器；第三方服务如何处理请求，以该服务商的隐私政策为准。不要提交不必要的敏感信息。
- AI 生成的释义、范文、译文、评分和建议可能不准确，仅作学习参考，不保证考试成绩；重要内容请对照教材、考试大纲和可靠来源。
- 真人发音、主动检查更新和用户点击的外部链接会访问对应第三方服务；离线时这些联网功能可能不可用。
- 桌面端数据位于 `word.exe` 同目录的 `data/`。删除该目录会使软件失去读取其中数据的能力；请勿把删除软件目录当作备份或可靠的数据擦除方式。

更多技术与开发说明见项目根目录 `README.md` 和 `HANDOVER.md`。
