# 考研英语学习平台

基于 Django 的考研英语一体化学习软件：词汇背诵、间隔复习、拼写与释义默写（AI 判定）、模拟考试、写作工坊（历年真题 AI 代写/批改）、学习统计与计划，开箱即用。

## 使用

1. 从 [GitHub Releases](https://github.com/1826548016-cloud/Lexizx/releases/latest) 下载最新版 `word.exe`，双击运行——弹出**原生桌面窗口**，首次启动约 1–2 分钟自动建库并导入词库与真题
2. AI 功能需先在「设置」页配置模型 API key
3. **关闭窗口即退出程序**
4. 老版本用户可在「设置 → 关于」点「检查更新」，检测到新版本后直接**下载并自动安装**（下载→SHA-256 校验→退出替换→自动重启），失败会自动回滚到旧版本

## 最后更新于2026年10月23日（v3.4.6）

本版说明：支持应用内一键更新（下载、校验、自动替换并重启），更新失败自动回滚；升级前自动备份数据库；修复释义判定偶发无反馈的问题。

学习数据保存在 `word.exe` 同目录的 `data` 文件夹中，删除软件前请先备份。启动异常可查看 `data/launch.log`。如使用中发现 bug，欢迎提交 issue。
